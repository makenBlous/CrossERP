# 可观测性

本文状态：**部分已实现；扩展方案仅设计**。

## 已实现

代码已有 `llm_call`、`llm_tool_call`、预算、告警、提示词版本、评测记录和安全事件审计；`observability/` 负责统计和导出。审计字段和链校验见 [审计](audit.md)。

## 目标

agent worker、实体动作和审批解析需要记录 request ID、委托身份、实体动作、权限结果、风险级别、幂等键、版本冲突和耗时。密钥、Token 和模型原始密文不得进入日志。只读与写草稿、待审、直接生效要能区分。

指标、事件字段和 worker 边界以 [08 第 4、10 章](design/08-后端模块与API设计.md) 为准；未实现部分不得标为生产监控已具备。
