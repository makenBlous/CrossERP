# 智能体与权限域指南

## 1. 范围与所属分期

覆盖登录人权限继承、数据范围、职责分离、委托通行证、agent/子智能体、风险分级、DeerFlow SDK worker、模型设置、MCP/注册函数和 AI 关闭后的人工兜底。权限底座在 P0，智能体、知识库和集成在 P4；目标依据 08 第 4、8、10、12 章。

## 2. 状态

- **已实现（代码核实）：** `src/crosserp/agent` 有只读数据库会话、9 个只读工具、规则检索、回答数字校验、模型环境变量读取；`src/crosserp/mcp_server` 有只读白名单和官方 MCP Server；网页 `/ask` 与 CLI `ask` 可调用运行时。
- **仅静态原型（前端 mock）：** G01–G26、W05、U05、SYS23 等页面，包括 AI 管理、权限查看、建议和审计页；页面 ID 以 [`pages.ts`](../../frontend/src/config/pages.ts) 为准。
- **仅设计：** DeerFlow 独立 agent worker、自动委托通行证、ActionDispatcher 五工具、完整权限矩阵和模型设置页，尚未在当前代码中核实。

## 4. 主要动作、权限与 AI 风险

完整动作看 08 第 4.4、4.6、10 章、实体 YAML `riskTier` 和 OpenAPI `x-crosserp.riskTier`。

| 风险 | AI 行为 | 典型动作 |
|---|---|---|
| 无（只读，L1） | 直接查询和解释，仍受登录人数据范围/字段权限 | 对账、利润、凭证、余额、报表、薪资查询、审计读取 |
| 低（L3） | 直接执行，不限次数 | 对账计算/匹配、报表运行、标签、可重算派生结果、知识体检、测试连通 |
| 中（L3） | 可直接改数据；24 小时内可撤销；不限次数；每天一条站内摘要 | 非钱账主数据、清洗问题、知识页草稿、对账差异处理、CRM |
| 高（L2） | 只能起草/待审；改账最多到这里 | 生成凭证、调账、过账、核销、付款、成本/汇率/分摊、对外发送 |
| 高危（L0） | AI 禁用，只能真人 | 权限治理写操作、审批决定、发起人确认、密钥/模型设置、薪资发布、结账、导出写账 |

子智能体与主智能体同一委托、同一风险级别和作用域；不能调用高危动作。管理员只能收紧，不得放宽。

## 5. 状态机

- `Delegation`：系统自动签发/续期；登出、切换账号、会话过期、权限变化、停用、关闭 AI 或降级时作废。单张最长 24 小时，无人工作页面。
- `AgentSuggestion`：`proposed → submitted → approved/rejected → executed`；中风险执行后 24 小时内可 `undone`，还可 `expired/dismissed`。
- `AgentRun`：排队、运行、完成/失败/停止；每个工具调用重新回查当前权限。
- `AgentMode`：正常 → 降级/关闭；恢复由真人操作。后台定时任务由 CrossERP 调度器发起，并按委托人当时权限重新签发通行证。
- `Approval`：通用审批状态机见 [财务](财务.md)；没有审批人时人发起自动生效，AI 发起进入本人确认分支。

## 6. 审批规则在本域的体现

- agent 继承登录人权限，只能少不能多；每一步与网页按钮走同一套权限、数据范围、字段策略、状态机和职责分离。
- 配置了审批人就必须审，法人/老大也不能自批；无审批人时人提交直接生效并留痕。
- AI 发起的高风险或钱账动作无可用审批人时进入 `awaiting_initiator`，只允许发起它的本人确认；AI 不能调用确认接口。
- 中风险通知只进每日一条站内摘要，用户可撤销；不弹窗、不推 IM/邮件，不设置次数上限。

## 7. 金额与会计口径

- AI 只读取确定性结果；不计算、不改写金额、匹配、利润或凭证。改账动作的最高自主等级为 L2。
- 金额使用万分位整数 `Money`；模型输入应带来源引用和字符串金额，不能以浮点传递。
- 模型配置仅三项：`baseUrl`、`apiKey`、`model`；`apiKey` 加密存储、不回显、不进日志。当前代码读取 `CROSSERP_MODEL_BASE_URL`、`CROSSERP_MODEL`、`CROSSERP_API_KEY`，这是已实现现状，不等于目标存储方案。

## 8. 验收标准

- [ ] 同一用户通过网页、CLI、MCP、主智能体和子智能体读取同一对象时，结果受同一权限和数据范围过滤。
- [ ] 用只读数据库会话执行 9 个现有工具：`get_profit`、`list_issues`、`get_order`、`get_settlement`、`get_recon_summary`、`get_approval_status`、`get_voucher`、`compare_profit`、`search_rules_doc`；确认无写操作。
- [ ] 模型回答含数字但没有工具引用时必须拒答；金额引用能回到表和字段。
- [ ] 分别测试只读、低、中、高、高危动作；确认改账只生成草稿/待审，高危动作被拒绝，中风险可撤销且只进每日摘要。
- [ ] 登录、登出、切换账号、权限变更、停用用户、关闭 AI 后，当前委托立即失效；下次消息无感重新签发。
- [ ] AI 关闭后人工导入、对账、利润、审批、凭证和导出流程仍可完成；主/子智能体回归结果和拒绝原因一致。
- [ ] MCP 默认 stdio；HTTP 未配置时拒绝启动，工具白名单与代码一致。
