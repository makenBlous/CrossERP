# ADR 0006：本体优先与数据进入链路

- 状态：已采用

## 背景

外部文件、清洗结果、业务实体和推演副本需要可追溯，避免每个入口实现一套业务规则。

## 决定

原件不可改，先清洗、校验、去重，再投射到 ontology 实体；网页、agent、导入和定时任务都调用实体动作执行器。推演只在副本上完成，确认后生成草稿进入审批。

## 后果

实体目录和动作成为接口、权限、审计和状态机的共同来源；数据链路更长，但可以回放和解释。
