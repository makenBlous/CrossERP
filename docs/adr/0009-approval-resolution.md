# ADR 0009：审批人解析与 AI 退回本人确认

- 状态：已采用

## 背景

审批人可能来自流程配置、角色或部门，不能用“单人模式”或金额阈值绕过职责分离。

## 决定

提交时按流程规则解析在职、未停用、有权限且数据范围覆盖的账号，并排除提交人和被代表人。有可用审批人必须审批；没有配置或解析不到时，人发起的单据直接生效并留痕，AI 发起的高风险或钱账动作进入 `awaiting_initiator`，由发起人本人确认后生效。审批不设金额上限。

## 后果

审批结果可解释、可审计；小团队可开箱使用，AI 无审批人时不会静默写账。
