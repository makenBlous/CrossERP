# ADR 0007：agent 委托权限与无感通行证

- 状态：已采用

## 背景

agent 需要代用户调用动作，又必须防止扩权、权限变化后继续使用旧身份。

## 决定

agent 继承登录人的权限，只能收窄。系统自动签发最长 24 小时的委托通行证并静默续期；登出、切换账号、权限变化、停用或关闭 AI 时立即作废。子智能体只传通行证编号，由 CrossERP 回查，不创建用户可操作的通行证页面。

## 后果

每一步都复用网页权限检查，运行中权限变化可停止后续动作；worker 不持有额外用户权限。
