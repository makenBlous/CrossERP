# ADR 0010：禁止 AI 执行代码

- 状态：已采用

## 背景

宿主机命令、沙箱和任意脚本会扩大数据泄露和越权风险，且无法统一审计。

## 决定

关闭 bash、文件写入工具和代码沙箱，不安装 Docker。脚本只能以注册函数或 MCP 工具提供，必须声明输入输出、权限点和风险级别，并进入统一动作执行器。

## 后果

工具开发需要显式注册和审查，但权限、风险、幂等和审计可以统一处理。
