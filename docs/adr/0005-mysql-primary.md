# ADR 0005：正式环境以 MySQL 8.4 为主

- 状态：已采用

## 背景

项目需在内网单法人环境稳定运行，同时保留 SQLite 演示和三库兼容现状。

## 决定

正式环境使用 MySQL 8.4 LTS；SQLite 仅作本机演示，PostgreSQL 为备选。连接、字符集、严格模式和迁移约束按 08 第 11 章执行。

## 后果

部署和运维以 MySQL 为基线，通用 SQLAlchemy 类型仍保证其他数据库可用。ADR 0004 的三库规则变为兼容现状。

## 依据（08 章节）

[08 第 11 章](../design/08-后端模块与API设计.md)。

## 状态

已采用；与 [ADR 0004](0004-three-databases.md) 并行，优先级更高。
