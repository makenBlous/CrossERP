# 安全

本文状态：**已实现现状 + 仅设计目标**。

## 已实现

现有代码提供 Argon2 密码哈希、会话、CSRF、锁定、API Token、角色权限、安全事件哈希链、导入原件留存和 agent 只读工具。LLM 不计算金额；现有代码的做法是写账必须经过审批和唯一写账出口。目标设计按 [ADR 0009](adr/0009-approval-resolution.md)：人提交时无审批人可直接生效并留痕，AI 改账最多到待审。

## 目标规则

agent 继承登录人权限，只能收窄；每一步复用网页权限检查。委托通行证自动签发、静默续期，并在登出、切换账号、权限变化、停用或关闭 AI 时作废。AI 不执行代码：关闭 bash、沙箱和 Docker，只允许注册函数或 MCP 工具。

正式环境为内网 MySQL 8.4、单法人；不把 API key、密码、Token、真实数据或内网地址写入仓库。审批人解析、风险五级、AI 退回本人确认见 [08 第 4、10 章](design/08-后端模块与API设计.md) 与 [ADR 0007–0010](adr/0007-agent-delegated-permission.md)。
