# W6 验收证据

T41 按推荐默认执行：批准请求内服务端生成 `kingdee_xlsx` 与 `generic_xlsx` 两种文件并消费一次性 token，网页只读取已保存产物。

## 自动化结果

```bash
.venv/bin/pytest tests/web -k voucher -q
.venv/bin/pytest tests -k "ledger or export or guard" -q
.venv/bin/crosserp check-golden
```

预期：凭证网页测试通过；写出、导出和红线守卫测试通过；原有黄金样例通过。

未批准或无权限下载会返回 403，并在 `audit_log` 记录 `ledger.export_denied`；缺少 `voucher.download` 权限时还记录 `permission_denied` security 事件。
