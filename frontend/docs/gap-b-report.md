## 本轮补齐

- 断点 1：订单增加 `customerId` / `opportunityId`，订单详情可跳客户与商机；客户和商机详情反向列出订单；业务链页可模拟商机赢单并生成带关联字段的销售订单草稿。
- 断点 2：采购退货增加 SKU、仓库、批次、数量明细；确认后写入负数库存流水，并按代码冲减应付发票，详情可追溯。
- 断点 4：订单详情与业务链展示物流运单/头程双向链接，运单可回到订单。
- 补货建议 → 采购单：AI 正常显示 AI 起草，AI 关闭保留手动起草；数量来自安全库存和销量代码，保存草稿并审计。
- 询价比价 → 采购单：人工选择供应商后生成带 `rfq_id` / `contract_id` 来源的采购单草稿。
- 调拨确认生成 `-80 / +80` 双流水；盘点先提交差异审批，批准后才过账。
- 领星/赛狐导入完成上传 → 列映射建议 → 人工确认 → 预览 → 导入；每一步写集成审计。
- 渠道与 IM：钉钉新增、测试发送、启停、身份绑定/解绑可保存；¥3,000 卡片可在飞书模拟批准，¥80,000 只能去网页，篡改哈希会阻止操作。
